# Archived Unsafe Actuation Prototype

This project is preserved only as historical source. It contains serial `ARM`/`FIRE` commands and drives GPIO13 high for an energized interval.

It is **not** part of Rocket 2027 production firmware, workspace, build verification or ObserveOnly safety architecture. **禁止 build-for-release、燒錄或在任何已接能源、點火器、切割器或作動器的硬體上操作。** See [`../../../docs/SAFETY.md`](../../../docs/SAFETY.md).

The original operating note is retained as `LEGACY_README.md` and is explicitly non-current.
