# Isolate the Reserved Payload interface

The Reserved Payload Envelope will provide constrained, isolated low-power and data interfaces whose payload side cannot backfeed, reset, block or command the Flight Computers, Recovery Authority or recovery paths. The payload receives only the residual budget owned by avionics.

## Consequences

Payload integration remains possible when 2027 requirements are known, but it cannot become a safety-critical dependency or create a new control path into recovery.
