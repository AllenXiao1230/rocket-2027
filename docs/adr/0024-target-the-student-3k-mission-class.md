# Target the Student 3K mission class

The rocket targets the Student 3K mission class for the 2027 Taiwan Cup. This avoids under-sizing recovery, RF, power and verification for a 3 km-scale mission while keeping actual eligibility, propulsion constraints, scoring and LRR evidence subject to the 2027 Competition Acceptance Gate.

## Consequences

The team will use a 3 km mission envelope for preliminary budgets and test planning, but will not copy 2026 limits, schedules or qualification details into the flight configuration without the 2027 official documents.
